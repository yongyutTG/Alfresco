# Folder navigation

Click a folder name to select it and load its documents. Clicking the selected
name again preserves normal listings without another API request. If search
results are displayed (including zero results), or the search box contains a
keyword, clicking the same name clears the search, resets to page one and loads
the folder listing. This also works if the keyword was cleared manually while
search results remain visible. Use Refresh when a fresh normal listing is needed.

The chevron only expands or collapses child folders. It does not change the
selected folder, search, page or document results. The first root expansion
loads its tree; subsequent clicks toggle the existing tree. Selecting a name
does not expand or collapse the tree.
